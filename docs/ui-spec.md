# nanoflow UI

Приложение для macOS на Flutter, которое показывает, что происходит в
прогонах графа.

Формат графа, модели хранилища и события описаны в [README](../README.md).

Макет: [nanoflow UI, вариант B](https://claude.ai/artifact/XE2GsHkzaQmho74b2atHWv);
снимок экранов — в [design/](design/): `start`, `graph`, `step-details`,
`task-graph`, каждый как HTML и PNG.

## Что это

- **Одно окно — один граф.** Открывается файл графа, сессии берутся из
  каталога `runs` в каталоге этого файла: предполагается, что
  `nanoflow run` запускают из него.
- **Только чтение.** Ничего не запускает, кроме
  `nanoflow-yaml <файл> --graph --watch` и `nanoflow check` из `PATH`, и не
  пишет ни в граф, ни в хранилище.
- **Всё живое.** Сессии, прогоны, шаги и строки лога появляются сами:
  приложение подписано на хранилище. Правки графа приходят через
  `--graph --watch`; каждое новое описание приложение отдаёт в stdin
  `nanoflow check` и так узнаёт его ошибки.
- **Граф двух видов.** Выбрана сессия — на холсте её снимок графа; выбран
  `Current graph` — текущий граф.
- **Граф отвечает «где сейчас», лента шагов — «как сюда пришли».**
- **Интерфейс на английском, время — в местном часовом поясе.** Тема тёмная.
- **Идентификаторы сокращены** до первых 4 символов UUID: `a1b2`. Полный —
  в подсказке при наведении.
- **Без песочницы macOS.** Приложение читает каталог `runs`, который
  пользователь не выбирал, и запускает программу графа — в песочнице ни то,
  ни другое нельзя.

## Стартовый экран

- **Заголовок `Graphs`** и кнопка **`Open graph`** справа от него.
  Кнопка открывает системный диалог выбора файла (`.yaml`, `.yml`);
  выбранный файл открывается в экране графа.
- **`Recently opened`** — список ниже, последние открытые сверху. В
  карточке имя файла, полный путь и когда открывали: `Opened 2 hours ago`.
  Клик открывает граф.
- **Файла больше нет** — карточка приглушена, имя зачёркнуто, метка
  `Missing`, клик не открывает. В карточке кнопка `Remove`.
- **Список пуст** — только заголовок, кнопка и строка о том, что открывать.

Приложение всегда стартует с этого экрана. С экрана графа сюда возвращает
ссылка `Graphs` в шапке. Других способов открыть граф — перетаскивания,
аргумента командной строки — нет.

## Экран графа

```text
┌─ Graphs / review.yaml ──────────────── Live · Reveal in Finder · Open in editor ┐
├─Sessions──┬─ Session a1b2 · running 12m ───────────────── Run [b7f2][c3d4][e5f6]┤
│ ▌14:03:11 │                                                                     │
│ ▌13:27:40 │   (collect)──▶[is-empty]──▶[inspect]──▶[verdict]──▶[notify]         │
│ ▌12:40:02 │                  граф слева направо                                 │
│           ├─Logs────────────────────────────────┬───────────────────────────────┤
│           │ шаги с таймлайном                   │ Input · Output · Log          │
└───────────┴─────────────────────────────────────┴───────────────────────────────┘
```

**Шапка:** ссылка `Graphs`, имя файла графа и его каталог. Справа метка
`Live`, кнопки `Reveal in Finder` и `Open in editor` для файла графа.

Под шапкой слева колонка сессий, справа холст графа, под холстом панель
`Logs`. Границы колонки и панели двигаются.

### Сессии

Над списком — пункт `Current graph`: текущий граф без сессии. Когда он
выбран, на холсте нет прогонов, счётчиков и меток, панель `Logs` пуста.

Ниже — сессии этого графа, новые сверху. Сессия — карточка с цветной полосой
статуса слева:

- **Первая строка** — день и время начала (`Today · 14:03:11`) и
  идентификатор сессии.
- **Вторая строка** — статус со временем и число прогонов.

| Статус   | Когда                                               | Строка                |
| -------- | --------------------------------------------------- | --------------------- |
| running  | Хотя бы один прогон не закончен.                    | `Running for 12m 26s` |
| failed   | Все прогоны закончены, хотя бы один — `run-failed`. | `Failed in 6m 18s`    |
| finished | Все прогоны закончены, сбоев нет.                   | `Finished in 3m 04s`  |

**Время сессии** — от первого `run-started` до конца последнего прогона; у
идущей — до текущего момента.

У идущей сессии с упавшими прогонами рядом со статусом — метка `1 failed`.

### Холст

**Строка сессии** висит поверх холста сверху: слева идентификатор сессии,
время начала и статус, справа переключатель прогонов `Run`. Холст под ней
двигается и масштабируется, сама она остаётся на месте; частью графа она не
является. Внизу слева кнопки масштаба:
вписать в окно, увеличить, уменьшить. Холст панорамируется. Фон — точечная
сетка.

**Переключатель прогонов** — прогоны сессии в порядке создания:
идентификатор и знак состояния — не начат (нет `step-started`), идёт,
закончен, сбой, разветвился (ещё и слово `split`). Выбранный залит
акцентным цветом.

**Шаги прогона** — его собственные и унаследованные: шаги предков от
корневого прогона до разветвления, породившего этот.

При выбранном `Current graph` строки сессии нет: сессии нет, значит нет ни
её статуса, ни прогонов. Остаются только кнопки масштаба.

### Граф

Алгоритм, который выполняет правила этого раздела, — в
[graph-layout.md](graph-layout.md).

**Раскладка автоматическая**: слева направо, слоями от узлов `start`. Один и
тот же граф всегда выглядит одинаково; узлы не перетаскиваются, позиции
нигде не хранятся. При смене сессии граф может измениться: у сессий разные
снимки.

**Узел — квадратная плитка.** В центре значок: у рабочего узла — терминал,
у развилки — вилка. Под плиткой имя узла, под ним команда моноширинным
шрифтом. Над плиткой узла из `start` — подпись `start`: особой формы у него
нет, это обычный узел, просто его имя названо в `start`.

**Вход** — короткая планка на левой грани плитки, по её середине. Она
есть, только если в узел приходит стрелка, — в том числе у узла из
`start`, если в него возвращаются. Вход запуска планки не рисует. Стрелки
входят в планку симметрично вокруг середины, не ближе 10 px друг к другу.
Планка не длиннее прямой части грани, на скругления не заходит; стрелок
больше, чем она вмещает, — растёт плитка, как под выходы.

**Выходы** — точки на правой грани плитки, по одному на каждую цель, кроме
списка:

- У рабочего узла выход без подписи.
- У развилки у каждого выхода подпись — ключ из графа, буквально: ключи
  карты `then`, `else`, у формы `if` — `true`.
- **Цель — список** (разветвление): выход один, вытянутый — капсула, из
  которой по стрелке на каждую цель. Стрелки выходят из капсулы через 14 px,
  капсула растёт под их число, плитка — под капсулу. Подпись и счётчик у
  капсулы одни: исход один, и все цели начинаются разом.
- **Нет `then`** — выходов нет совсем: узел заканчивает прогон.
- **Цель пуста** — вместо стрелки отросток с поперечной чертой на конце;
  подпись и счётчик у него как у стрелки. Такие выходы — последние на
  плитке, `else` среди них — самый последний. Отросток не короче подписи с
  местом под счётчик, даже когда счётчика нет.

**Стрелка** идёт от одного выхода к входу одного узла. Стрелки не
ветвятся и не сливаются. Стрелка в узел более раннего слоя — возврат:
пунктир, огибает граф снизу.

**Как проложена стрелка:**

- **Только три направления** — горизонталь, вертикаль и диагональ в 45°.
- **Углы скруглены** одинаковым радиусом.
- **У обоих концов горизонтальный участок:** стрелка выходит вправо и
  подходит слева. Начальный вмещает подпись выхода со счётчиком, даже если
  счётчика нет; конечный — не короче 20 px.
- **Между параллельными участками не меньше 10 px.**
- **Цель — меньше пересечений.** Из двух раскладок лучше та, где
  пересечений меньше; при равенстве — где больше стрелок идёт параллельно.
  Это цель, а не условие: проверяется только, что пересечений не больше,
  чем в сохранённой эталонной раскладке того же графа.
- **Петля** — стрелка узла в себя — идёт над плиткой или под ней, вплотную,
  от крайнего выхода к крайнему входу с этой стороны. Петли с одной стороны
  занимают крайние выходы и входы подряд; чем дальше выход от края, тем шире
  петля.
- **Линия кончается у основания наконечника**, остриё дорисовывает он сам.
  Иначе торец линии вылезает по бокам и остриё выглядит срезанным.
- **Между остриём и планкой зазор.** Стрелка на планку указывает, а не
  упирается в неё и тем более не налезает.
- **Наконечники одного размера** у всех стрелок и не зависят от толщины
  линии.

**Счётчик на стрелке** — `1×`, `2×`: сколько раз прогоны сессии прошли по
ней. У стрелок, по которым не ходили, счётчика нет, и они темнее. Счётчик
стоит у начала стрелки, сразу за ключом исхода; у выхода без ключа — на его
месте. Так исходы одного узла выстраиваются в столбик и видно, куда чаще
уходило; сколько раз пришли в узел, и так написано на плитке.

**У подписи непрозрачная подложка** цвета холста: стрелка проходит за ней,
а не сквозь. Подложка не закрывает наконечники и не залезает на узлы.

**Состояние узла** считается по всем прогонам выбранной сессии:

| Состояние   | Когда                           | Вид                                    |
| ----------- | ------------------------------- | -------------------------------------- |
| failed      | На узле упал прогон.            | Красная рамка, знак `!` в углу.        |
| running     | На узле есть незавершённый шаг. | Жёлтая рамка, вращающийся знак в углу. |
| visited     | Есть завершённые шаги.          | Зелёная рамка, галочка в углу.         |
| not visited | Шагов нет.                      | Серая рамка, значок приглушён.         |

Если подходят несколько, побеждает верхнее.

**Метки над плиткой**, в правом верхнем углу:

- **Прогон на узле** — идентификатор прогона, цветом его состояния. Так
  отмечен каждый прогон сессии, кроме разветвившихся, на узле своего
  последнего шага; не начатый — на своём стартовом узле.
- **Счётчик заходов** `2×` — если узел пройден больше одного раза.

**Путь выбранного прогона** — акцентный цвет у стрелок, выходов и входов,
по которым прошли его шаги.

**Узел выбранного шага** обведён акцентным кольцом.

### Logs

Панель под холстом. В заголовке — выбранный прогон и число шагов: `run e5f6
· 8 steps, 7 inherited from b7f2`. Слева лента шагов, справа детали
выбранного шага.

**Лента шагов** — шаги выбранного прогона по порядку. Унаследованные
приглушены, на каждом разветвлении разделитель `split · run e5f6`. Колонки:

| Колонка  | Что                                                                                                   |
| -------- | ----------------------------------------------------------------------------------------------------- |
| значок   | Состояние шага: завершён, идёт, сбой.                                                                 |
| Step     | Имя узла. У развилки — исход и куда пошли: `returned → fix`. У сбоя — строка `error` из `run-failed`. |
| Started  | Время первого `step-started`.                                                                         |
| Took     | До `step-finished`. У идущего шага — тикающий счётчик.                                                |
| таймлайн | Полоса на общей шкале — времени сессии. У идущего шага полоса штрихована.                             |

- **Перезапущенный шаг** — несколько `step-started` — помечен `2 starts`.
- **Последняя строка ленты** — состояние прогона, если он кончился; у
  разветвившегося — ссылки на потомков.
- **Слежение.** Пока выбран последний шаг идущего прогона, выбор сам
  переходит на новый шаг. Выбрал другой шаг — слежение выключено; вернулся
  на последний — включено.

**Детали шага** — вкладки `Input`, `Output`, `Log` и кнопка `Open`,
открывающая окно деталей шага.

- **Данных нет**: у узла не объявлен `in` или `out` — вкладка помечена `—`;
  шаг ещё идёт — «пока нет».
- **`Log`** — моноширинный текст лога шага. У идущего шага прокрутка
  держится за хвостом, пока пользователь не прокрутил вверх; пока держится,
  видна метка `following tail`.
- **С файловым хранилищем** внизу — путь к файлу открытой вкладки и кнопки
  `Finder`, `Editor`, копировать путь.

### Окно деталей шага

Открывается кнопкой `Open` в ленте или двойным кликом по узлу. Занимает
почти весь экран поверх холста.

**Верхняя строка:** `Back to canvas`, значок и имя узла с командой или функцией,
переключатель заходов `Visit 2 of 2` по всем заходам в этот узел в
выбранной сессии, прогон этого захода, итог (`exit 0 · 4m 02s`), закрыть.

Ниже три колонки:

- **Input.** Строка «from `<узел> · <время>`» — шаг, из выхода которого
  пришёл вход; клик переходит к нему. У стартового шага — «вход запуска».
  Метка типа `in` и данные.
- **Узел.** Команда или функция узла. Карточки `in` и `out` с
  типами. Цели: `then` у рабочего узла; у развилки — исходы с их целями.
  Факты шага: `Started`, `Finished` и длительность, `Exit code`, `Starts` —
  все запуски, с пометкой прерванных. С файловым хранилищем внизу —
  каталог шага, `Reveal in Finder`, копировать путь.
- **Output.** Вкладки `Output` и `Log`. У выхода — проверка по `out`
  («passes `#/Report`» или ошибка).

**Данные** в `Input` и `Output` показаны в виде `Schema` или `JSON`:
`Schema` — поля с типом и значением, вложенные объекты и массивы
сворачиваются; `JSON` — текст с подсветкой. Большие данные показаны не
целиком: у JSON — начало, у лога — хвост, и кнопка «показать всё».

Двойной клик по узлу без заходов открывает окно с пустыми `Input` и
`Output`: видно только описание узла.

### Выбор

- **При открытии графа** выбрана самая новая сессия; сессий нет —
  `Current graph`.
- **При открытии сессии** выбран первый идущий прогон; нет таких — первый
  упавший; нет и таких — последний по времени. В нём выбран последний шаг.
- **Шаг в ленте** прокручивает холст к своему узлу, если тот не виден.
- **Клик по узлу** выбирает в ленте его последний шаг среди шагов
  выбранного прогона. Шагов нет — ничего не происходит.
- **Новые данные выбор не сбрасывают.**

## Когда что-то не так

| Что случилось                        | Что видно                                                                                                     |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| Текущий граф не проходит `check`     | Список ошибок; на холсте — последний граф без ошибок, если такого ещё не было — надпись `No valid graph yet`. |
| Файл графа не разбирается            | Ничего не меняется, пока файл не исправят.                                                                    |
| У графа нет сессий                   | Граф нарисован, вместо списка сессий — `No runs yet` и подсказка про `nanoflow run`.                          |
| Событие журнала записано не до конца | Событие не учитывается, пока не допишется.                                                                    |
| Событие не разбирается или незнакомо | Событие пропущено, у прогона значок `Log read incompletely`.                                                  |
| Файл графа удалён, пока он открыт    | Остаётся последний прочитанный граф и плашка «файл недоступен».                                               |

Шаг, оборванный падением движка, по хранилищу не отличить от идущего.
Приложение показывает его как идущий.

## Вне объёма

- Решения человека, которых ждёт узел.
- Документация узлов.
- Системные уведомления.
- Поиск по логам и данным, фильтры сессий.
- Общий список сессий разных графов.
- Прогоны на другой машине.
- Linux, Windows, веб и мобильные платформы.
- Mac App Store: туда без песочницы не пускают.
