# nanoflow UI

Приложение для macOS на Flutter, которое показывает граф воркфлоу,
прочитанный из кода, и его сессии вживую.

Файл графа, модели хранения и события описаны в [README](../README.md).

Макет: [nanoflow UI, вариант B](https://claude.ai/artifact/XE2GsHkzaQmho74b2atHWv);
снимок экранов — в [design/](design/): `start`, `graph`, `step-details`,
`task-graph`, каждый как HTML и PNG. Рамки функций и копий — в
[design/code-first/](design/code-first/): `function-frames`, `copies-frame`,
`copy-switcher`, только HTML; надписи там по-русски, в приложении — по-английски.

## Что это

- **Одно окно — один файл графа.** Открывается `nanoflow.graph.json`,
  сессии берутся из каталога `runs` рядом с ним: библиотека пишет их в тот
  же каталог проекта.
- **Только чтение.** Приложение ничего не запускает и не пишет ни в файл
  графа, ни в хранилище.
- **Всё живое.** Сессии, эффекты и строки лога появляются сами: приложение
  подписано на хранилище. Файл графа перечитывается, когда меняется, —
  `describe --watch` переписывает его при каждой правке кода.
- **Граф двух видов.** Выбрана сессия — на холсте её снимок графа; выбран
  `Current graph` — файл графа, как он есть.
- **Граф отвечает «где сейчас», лента эффектов — «как сюда пришли».**
- **Интерфейс на английском, время — в местном часовом поясе.** Тема тёмная.
- **Идентификаторы сокращены** до первых 4 символов UUID: `a1b2`. Полный —
  в подсказке при наведении.
- **Без песочницы macOS.** Приложение читает каталог `runs`, который
  пользователь не выбирал, — в песочнице это нельзя.

## Стартовый экран

- **Заголовок `Graphs`** и кнопка **`Open graph`** справа от него.
  Кнопка открывает системный диалог выбора файла (`.json`); выбранный файл
  графа (`*.graph.json`) открывается в экране графа. Другой файл —
  заметка `<имя> is not a graph file: open nanoflow.graph.json`.
- **`Recently opened`** — список ниже, последние открытые сверху. В
  карточке — каталог проекта (файл графа у всех называется одинаково),
  полный путь и когда открывали: `Opened 2 hours ago`. Клик открывает граф.
- **Файла больше нет** — карточка приглушена, имя зачёркнуто, метка
  `Missing`, клик не открывает. В карточке кнопка `Remove`.
- **Список пуст** — только заголовок, кнопка и строка о том, что открывать.

Приложение всегда стартует с этого экрана. С экрана графа сюда возвращает
ссылка `Graphs` в шапке. Других способов открыть граф — перетаскивания,
аргумента командной строки — нет.

## Экран графа

```text
┌─ Graphs / nanoflow.graph.json / review › publish()  ~/app ─── Live · Reveal in Finder · Open in editor ┐
├─Sessions──┬─ Session a1b2 · started 14:03:11 · ● running 12m 26s ──────────────────────────────────────┤
│ Current   │                                                                                            │
│ ▌14:03:11 │   [start]──▶(collect)──▶◇──▶(inspect)──▶◇──▶[publish() +]──▶[end]                          │
│ ▌13:27:40 │                  граф слева направо                                                        │
│           ├─Logs───────────────────────────────────┬───────────────────────────────────────────────────┤
│           │ эффекты с таймлайном                   │ Output · Log                                      │
└───────────┴────────────────────────────────────────┴───────────────────────────────────────────────────┘
```

**Шапка:** ссылка `Graphs`, имя файла графа, крошки уровней графа
(`release › publish() › upload()`) и каталог файла. Справа метка
`Live · watching runs/`, кнопки `Reveal in Finder` и `Open in editor` для
файла графа.

- **Крошка выше нарисованного уровня** возвращает на него.
- **Шеврон у крошки воркфлоу** — выбор воркфлоу, когда их больше одного:
  воркфлоу файла графа по порядку, потом те, по которым шли сессии, но
  которых в файле нет, с пометкой `not in the graph file`. Выбранный
  рисуется со своего верхнего уровня.
- **Крошкам не хватает места** — средние сворачиваются в `…` со списком; в
  самом узком окне сворачивается и крошка воркфлоу, шеврон остаётся впереди.
- **С файлом что-то не так** — метка вместо `Live` говорит
  `File unavailable` или `File unreadable` (ошибка — в подсказке).

Под шапкой слева колонка сессий, справа холст графа, под холстом панель
`Logs`. Границы колонки и панели двигаются; панель сворачивается до
заголовка.

### Сессии

Над списком — пункт `Current graph`: файл графа без сессии. Когда он
выбран, на холсте нет эффектов, отметок и меток, панель `Logs` пуста.

Ниже — сессии выбранного воркфлоу, новые сверху. Сессия — карточка с цветной
полосой статуса слева:

- **Первая строка** — день и время начала (`Today · 14:03:11`) и
  идентификатор сессии.
- **Вторая строка** — статус со временем и число эффектов: `8 effects`.
- **Строка заметок** — `1 failed`: у идущей сессии упали эффекты, воркфлоу
  поймал их исключения или ещё не дошёл до них (макет `graph` ставит эту метку
  рядом со статусом, приложение — первой в строке заметок, чтобы статус и число
  эффектов не обрезались); `other code` или `not checked`: сессия шла не на том
  коде, из которого прочитан её граф, или не записала хэш кода;
  `resumed on changed code`: сессию продолжили на другом коде, чем начали (хэши
  кода `session-started` и какого-то `session-resumed` известны и различаются),
  — её эффекты до того шли на другом коде (решение 7); и
  `Log read incompletely`: журнал прочитан не весь, почему — в подсказке. Не
  помещаются рядом — следующая уходит под предыдущую; строку статуса они не
  теснят. `other code` видна и у сессии, которую не открывали: последний снимок
  продолжения читается для каждой сессии списка.

| Статус      | Когда                                                            | Строка                      |
| ----------- | ---------------------------------------------------------------- | --------------------------- |
| running     | Последнего события сессии ещё нет.                               | `Running for 12m 26s`       |
| failed      | Последнее событие — `session-failed`.                            | `Failed in 6m 18s`          |
| finished    | Последнее событие — `session-finished`.                          | `Finished in 3m 04s`        |
| interrupted | Последнего события ещё нет, а процесса, который вёл сессию, нет. | `Interrupted after 10m 12s` |

**Время сессии** — от `session-started` до её последнего события; у идущей —
до текущего момента, у прерванной — до последнего события журнала: когда
процесс ушёл, журнал не знает, поэтому `after`.

**Прерванная сессия** — читатель сказал о ней `owner-changed` с
`alive: false`: процесса-владельца нет, он вышел, или его pid теперь у
другого процесса
([владелец сессии](superpowers/specs/2026-10-03-session-owner-design.md)).
Полоса статуса и строка — приглушённые серые, не янтарь идущей; подсказка у
статуса —
`The process that ran this session is gone; resume it to finish.` Эффект,
который шёл, прерван — на графе, в `Logs` и в окне эффекта; его время не идёт.
Пока `owner-changed` не пришло, и при `alive` `true` или `null` (узнать
нельзя) сессия идёт, как раньше. Переход — без действий пользователя:
пришло `owner-changed` — карточка, строка сессии, граф и `Logs`
перерисованы; продолжили сессию (`--resume`) — новый владелец жив, и она
снова идёт.

**Воркфлоу сессии — имя функции.** Сессии одноимённых воркфлоу из разных
файлов не различить: они все — у первого такого воркфлоу файла графа.

### Холст

**Строка сессии** висит поверх холста сверху:
`Session a1b2 · started 14:03:11 · ● running 12m 26s`; у прерванной — серое
`● interrupted after 10m 12s` с той же подсказкой, что в карточке; у сессии,
продолженной на изменённом коде, — ещё `· resumed on changed code`. Холст
под ней двигается и масштабируется, сама она остаётся на месте; частью графа
она не является. Под ней — [заметки](#когда-что-то-не-так).

Холст панорамируется перетаскиванием, колесом и двумя пальцами,
масштабируется щипком, колесом с ⌘ или Ctrl и кнопками внизу слева:
вписать в окно, увеличить, уменьшить. Внизу справа — легенда: пунктир —
обратная стрелка, когда такие есть. Фон — точечная сетка.

Граф вписывается в холст при первом показе и когда на холсте другой граф
(у сессий разные снимки), но не от новых данных той же сессии; крупнее
нарисованного он при этом не становится. Тот же уровень, нарисованный
иначе, — файл графа переписан после правки кода — масштаб не меняет: узел,
ближайший к середине холста, остаётся на своём месте экрана; пока вид
таков, каким его оставило вписывание, граф вписывается заново.

При выбранном `Current graph` строки сессии и легенды нет: остаются только
кнопки масштаба.

### Граф

Алгоритм, который выполняет правила этого раздела, — в
[graph-layout.md](graph-layout.md).

**На холсте один уровень** — тело одной функции: сначала тело воркфлоу.
Двойной клик по вызову рисует тело его функции (у вызова метода
интерфейса — сначала выбор реализации), по копиям — тело копии; путь —
крошками в шапке.

**Раскладка автоматическая**: слева направо, слоями от маркера `start`.
Одно и то же тело всегда выглядит одинаково; узлы не перетаскиваются,
позиции нигде не хранятся. При смене сессии граф может измениться: у сессий
разные снимки.

**Узел — квадратная плитка**, вид — по виду узла:

- **эффект** — значок терминала;
- **развилка** — ветка: узел слева, от него два узла справа;
- **вызов** — одна плитка со знаком функции `ƒ` (`ƒ` с `×`, как «f(x)»), под
  ним мелко и приглушённо — сколько эффектов может пройти в функции:
  `{ 3 }`; `{ 1–2 }` у реализаций метода с разным числом эффектов, `{ ? }`,
  когда функции нет в файле, `{ }` без эффектов;
- **копии** — стопка из трёх плиток: стопка значит «их несколько». На плитке
  тот же знак `ƒ`, под ним — эффекты одной копии; на углу стопки — число
  копий: `×3`, `×0` приглушённо, пока копий нет, `×n` без сессии;
- **маркеры `start` и `end`** — пунктиром, со словом внутри. `end` — на
  каждый выход из тела свой, рядом с узлом, откуда выходит.

Под плиткой — имя (эффект — своё имя, развилка и копии — подпись, вызов — имя
функции с `()`; длиннее 30 знаков обрезано, целиком — в подсказке) и под
ним место в коде моноширинным шрифтом: `review.dart:49`.

**Вход** — короткая планка на левой грани плитки, по её середине. Она
есть, только если в узел приходит стрелка. Стрелки входят в планку
симметрично вокруг середины, не ближе 10 px друг к другу. Планка не длиннее
прямой части грани, на скругления не заходит; стрелок больше, чем она
вмещает, — растёт плитка, как под выходы.

**Выходы** — точки на правой грани плитки, по одной на подпись рёбер:

- У ребра без подписи — выход без подписи.
- У развилки подпись выхода — подпись ребра: `true`/`false`, `each`/`done`,
  исходник случая `switch` или `default`.
- **`true` выше `false`** — всегда, даже ценой пересечений: петля `true`
  над плиткой, петля `false` под ней.
- **Несколько рёбер с одной подписью** (ветки `Future.wait`): выход один,
  вытянутый — капсула, из которой по стрелке на ребро. Стрелки выходят из
  капсулы через 14 px, капсула растёт под их число, плитка — под капсулу.
  Подпись у капсулы одна.
- **Рёбер нет** — выходов нет: путь здесь кончается (`throw`).

**Стрелка** идёт от одного выхода к входу одного узла. Стрелки не
ветвятся и не сливаются. Стрелка в узел более раннего слоя — возврат
(петля цикла): пунктир, огибает граф снизу, а сверху — если так меньше
пересечений.

**Как проложена стрелка:**

- **Только три направления** — горизонталь, вертикаль и диагональ в 45°.
- **Углы скруглены** одинаковым радиусом.
- **У обоих концов горизонтальный участок:** стрелка выходит вправо и
  подходит слева. Начальный вмещает подпись выхода; конечный — не короче
  20 px.
- **Между параллельными участками не меньше 10 px.**
- **Цель — меньше пересечений.** Из двух раскладок лучше та, где
  пересечений меньше; при равенстве — где больше стрелок идёт параллельно.
  Это цель, а не условие: проверяется только, что пересечений не больше,
  чем в сохранённой эталонной раскладке того же тела.
- **Петля** — стрелка узла в себя — идёт над плиткой или под ней, вплотную,
  от крайнего выхода к крайнему входу с этой стороны. Петли с одной стороны
  занимают крайние выходы и входы подряд; чем дальше выход от края, тем шире
  петля.
- **Линия кончается у основания наконечника**, остриё дорисовывает он сам.
  Иначе торец линии вылезает по бокам и остриё выглядит срезанным.
- **Между остриём и планкой зазор.** Стрелка на планку указывает, а не
  упирается в неё и тем более не налезает.
- **Наконечники одного размера** у всех стрелок и не зависят от толщины
  линии.

**Счётчиков на стрелках нет, путь не подсвечивается:** по журналу не везде
видно, куда код свернул (см. «Развилки» ниже), — темнее только то, куда он
пойти не мог. Стрелки, выходы и планки — одного тона; темнее стрелки
пройденной развилки, по которым не мог пойти ни один переход, и в теле
одной выбранной копии стрелки к узлам, до которых она не дошла, и от них.
Места под счётчики раскладка не держит: сколько раз код прошёл развилку,
говорит `2×` над её плиткой.

**У подписи непрозрачная подложка** цвета холста: стрелка проходит за ней,
а не сквозь. Подложка не закрывает наконечники и не залезает на узлы.

**Эффекты на узлах — по месту вызова.** Эффект стоит на узле `effect` с тем же
`place`; путь сравнивается по окончанию после `/`. Из узлов этого места — на
тех, у кого то же имя: два эффекта на одной строке
(`Future.wait([f.effect('lint', …), f.effect('test', …)])`) стоят каждый на
своём. Нет узла с таким именем (имя задано выражением, у узла — его
исходник) — эффект на всех узлах места. Одно место и имя бывает у нескольких
узлов (`finally`, нарисованный на каждый выход из `try`) — эффект отмечается на
всех. На вызове — эффекты в его функциях, на копиях — эффекты в их теле. У
маркеров отметок нет; развилки отмечаются по переходам между эффектами (см.
«Развилки» ниже). Эффект без места или без своего узла — «не на графе»: о
нём заметка над холстом и строка в `Logs`.

**Состояние узла** считается по эффектам выбранной сессии на нём:

| Состояние   | Когда                                                   | Вид                                           |
| ----------- | ------------------------------------------------------- | --------------------------------------------- |
| failed      | Эффект на узле упал: в последний раз бросил.            | Красная рамка, знак `!` в углу.               |
| running     | На узле идёт эффект.                                    | Жёлтая рамка, вращающийся знак в углу.        |
| interrupted | На узле эффект, который шёл, когда процесс сессии ушёл. | Серая рамка, знак паузы в углу; не вращается. |
| visited     | Есть завершённые эффекты.                               | Зелёная рамка, галочка в углу.                |
| not visited | Эффектов нет.                                           | Серая рамка, значок приглушён.                |

Если подходят несколько, побеждает верхнее.

**Метка над плиткой**, в правом верхнем углу: `2×` — на узле больше
одного эффекта или код прошёл развилку больше одного раза. В теле копий, когда
показаны все, вместо неё у эффекта — сколько копий сейчас на нём, у развилки
— ничего.

**Развилки** отмечаются по журналу, без вычисления условий (спека
code-first, §9 «Развилки»): эффект и код перед ним — его предшественник по
`after` или, после вызова и ожидания, эффекты, на которых они кончились, —
переход по стрелкам уровня; через что проходит каждый путь перехода, то
пройдено.

- **Пройденная развилка** — в облике пройденного эффекта: зелёная рамка,
  галочка в углу; `2×`, если код прошёл её больше одного раза (насколько
  это различает журнал). Пройденной может оказаться и развилка, которую код
  не проходил, а рядом с ней — пройденные стрелки, которыми он не шёл: когда
  эффекты шли рядом и один кончился до начала другого (журнал не отличает
  это от ожидания) и когда функция шла больше раза (концы прежнего вызова
  читаются собранными перед эффектом следующего) — дизайн эффектов, §5.3
  «Пределы».
- **Остальные развилки** — без отметок, как без сессии: не найденный путь
  через развилку не значит, что код там не был.
- **Выход пройденной развилки**, которым код не мог пойти, — стрелка
  темнее; остальные — обычного тона. Пока сессия идёт — и когда она упала
  или прервана, — выход, которым код мог уйти от последних эффектов, не
  темнеет. В теле вызываемой функции выход темнеет, только если ни на
  одном её узле эффекта нет больше одного эффекта: иначе функция могла идти
  больше раза, а тогда по журналу не видно, каким путём прежний вызов из неё
  вышел, и не темнеет ни один выход. Условие нужно, но его мало: вызовы,
  чьи ожидания или замыкания шли на разных узлах, могут затемнить выход,
  которым прежний ушёл. Темнее может оказаться выход, которым код прошёл, и
  когда эффекты шли рядом — в том числе быстрые эффекты одного ожидания,
  кончившиеся в миллисекунду начала (дизайн эффектов, §5.3 «Пределы»).
- **Все копии:** развилка отмечена, если её прошла хоть одна копия, без
  `2×`; стрелки не темнеют. **Одна копия** — только её переходы.
  `Current graph` — ничего.

**Узел выбранного эффекта** обведён акцентным кольцом. Кольцо лежит под
стрелками: планка входа и половинка точки выхода остаются поверх него,
обе в контуре цвета холста шириной 1 px, который отделяет их от кольца.
Имя узла при выборе не меняется.

### Вызовы и копии на месте

Кнопка `+` в правом верхнем углу плитки вызова или копий раскрывает узел
на месте — рамкой с его телом, не уходя с уровня (у вызова метода
интерфейса — сначала выбор реализации). `−` на рамке сворачивает её.

- **Рамка вызова** — серая сплошная обводка цвета рамки плиток, без фона,
  слева вверху `publish()`, справа `−`.
- **Рамка копий** — та же рамка-стопка, что у открытого тела копий: с
  подписью, переключателем копий, строкой внизу и `−`.
- **Стрелка в рамку идёт сквозь её левую сторону** дальше, к первому узлу
  тела.
- **Конец тела — планка на правой стороне рамки**, как планка входа плитки:
  той же ширины, середина ширины — на линии стороны, в тоне выхода рамки, в
  контуре цвета холста. Стрелки к концу тела — каждый `return`, конец каждой
  ветки — указывают на неё каждая на своей высоте, с наконечником и зазором,
  по правилам входа плитки, — если надо, дотягиваясь до стороны рамки.
  Стрелка дальше выходит из середины планки: кружка выхода у рамки нет —
  планка и есть выход (макет `function-frames` рисует кружок). Стрелок
  дальше несколько (ветки `Future.wait` после вызова) — капсулы тоже нет:
  они выходят из планки, и она выступает за крайние из них, как за крайние
  стрелки к ней. Тело без конца — без планки; стрелка из такой рамки
  выходит из кружка или капсулы, как у плитки.
- **В рамке всё как на уровне:** отметки эффектов, клик, двойной клик, `+`;
  рамки в рамках — на любой глубине.
- **Раскрытый или свёрнутый узел остаётся на месте экрана;** пока вид
  таков, каким его оставило вписывание, граф вписывается заново.
- **Раскрытое помнится** для любой сессии воркфлоу и забывается для другого
  воркфлоу; свёрнутая рамка забывает раскрытое в ней.
- **Переписанный файл графа** нумерует узлы заново: id — порядок узлов в
  коде, и правка его сдвигает. Открытые уровни и раскрытые узлы идут за
  своими узлами: узел узнаётся по тому, что он такое — имя эффекта,
  функции вызова, подпись копий, условие развилки, — и по тому, сколько
  таких же стоит перед ним в теле. Узла нет — уровень закрывается и
  открывается снова, когда файл, переписанный позже, вернёт узел;
  раскрытый узел сворачивается. Снимок сессии на холсте от этого не
  меняется, и раскрытое на нём тоже.

### Копии

Тело, которое `Future.wait` выполняет копиями, открытое двойным кликом или
раскрытое на месте, — рамка-стопка: за ней видны ещё две. Над телом —
подпись `each pkg in packages` и напротив `×3 · in parallel`, под ней —
переключатель копий, внизу рамки — где копии.

**Копия** — цепочка эффектов рамки по `after`: первый эффект копии — тот, чей
предшественник вне рамки, каждый следующий — в копии своего
предшественника. Номер копии — по времени её первого `effect-started`. Копия
названа по переменной цикла — `pkg 2`, без неё — `copy 2`; копии в копиях
нумеруются внутри копии вокруг: `pkg 2 › target 1`.

**Предел.** Копию рамки вокруг узнают по её первому эффекту. Если в копии
рамки вокруг до внутренних копий нет ни одного эффекта
(`Future.wait([for (p in pkgs) Future.wait([for (t in targets) f.effect('build', …)])])`),
предшественник каждого эффекта внутренних копий — вне обеих рамок: каждый
такой эффект — своя копия рамки вокруг, и копии `p` не различить.

Эффект относят к рамке по месту, а не по пути вызова. Функцию, которую
вызывают и внутри рамки копий, и вне её, рамка считает своей: каждая
цепочка эффектов вызова вне рамки — тоже её копия. Копии внутри такой функции
в `Logs` названы раз — внутри копии рамки вокруг (`r 3 › s 1`), сколько бы
вызовов к ней ни вело.

**Переключатель копий** — `all · 1 ✓ · 2 ● · 3 ●`: номера по порядку старта
со знаком состояния (готова, идёт, упала; прервана — пауза), выбранный
залит. Над номером — подсказка: начало результата первого эффекта копии
(`core:uploaded`), чтобы узнать копию, не зная кода.

- **`all`** — по умолчанию: на эффектах внутри — сколько копий сейчас на
  эффекте, внизу рамки `done 1 of 3` (`· 1 failed`), `Logs` — эффекты всех копий
  с копией в каждой строке.
- **Тела внутри всех копий** — функция, открытая из тела копий, где показаны
  все, и вызов, раскрытый в нём на месте, — показаны как все копии: на
  эффектах — сколько копий сейчас на них, у развилок нет `2×`, стрелки не
  темнеют.
- **Номер копии** — на рамке только её эффекты, стрелки к узлам, до которых она
  не дошла, темнее; внизу `pkg 2 · now verify` (`done`, `failed at verify`,
  у прерванной сессии — `interrupted at verify`);
  `Logs` — эффекты только этой копии, её последний эффект выбран.
- **Копий больше 12** — одна кнопка с выбранной копией, она открывает
  список с поиском и фильтром `running` / `failed` / `done`; у прерванной
  сессии вместо `running` — `interrupted`: идущих копий у неё нет.
- **Копии в копиях** выбираются, когда выбрана копия рамки вокруг; до того
  переключатель говорит `choose the outer pkg first`.
- **Выбор копии один** для рамки, открытой двойным кликом и раскрытой на
  месте; для другой сессии он забывается. Раскрыто несколько рамок с
  выбранной копией — `Logs` у той, где выбрали последней.

### Logs

Панель под холстом. В заголовке — число эффектов: `8 effects`, при выбранной
копии — `pkg 2 · 3 effects`. Слева лента эффектов, справа детали выбранного
эффекта.

**Лента эффектов** — эффекты сессии по первому `effect-started`; при выбранной
копии — её эффекты. Колонки:

| Колонка  | Что                                                                                                                                                                                                                 |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| значок   | Состояние эффекта: завершён, идёт, сбой; прерван — серая пауза: процесс сессии ушёл, пока эффект шёл.                                                                                                               |
| Effect   | Имя эффекта. У сбоя — `error` из `effect-failed`, у эффекта не на графе — `not on the graph`, при всех копиях — копия эффекта: `pkg 2 › target 1`; так же у эффектов копий в нераскрытых копиях и в вызовах уровня. |
| Started  | Время первого `effect-started`.                                                                                                                                                                                     |
| Took     | До итога последнего запуска. У идущего эффекта — тикающий счётчик; у прерванного — `—`: когда он кончился бы, неизвестно.                                                                                           |
| таймлайн | Полоса на общей шкале — времени сессии. У идущего эффекта полоса штрихована; у прерванного — серая рамка без заливки до конца шкалы.                                                                                |

- **Перезапущенный эффект** — несколько `effect-started` — помечен `2 starts`.
- **Последняя строка ленты** у законченной сессии — как она кончилась и
  когда: `Session finished` или `Session failed: <ошибка>`.
- **Прокрутили вниз** — сверху `↑ 8 earlier effects`, клик прокручивает
  вверх.
- **Слежение.** Пока выбран последний эффект идущей сессии (при выбранной
  копии — её последний), выбор сам переходит на новый эффект. Выбрал другой
  эффект — слежение выключено; вернулся на последний — включено.

**Детали эффекта** — имя эффекта, вкладки `Output` и `Log` (входа у эффекта нет:
данные он берёт из замыкания) и кнопка `Open`, открывающая окно деталей эффекта.

- **`Output`** — документ выхода как JSON. Эффект идёт —
  `Not yet: the effect is still running`; прерван —
  `Not yet: the effect was interrupted — the process stopped`; упал — его
  ошибка; закончился без выхода — `The effect gave no output`.
- **`Log`** — моноширинный текст лога эффекта. У идущего эффекта прокрутка
  держится за хвостом, пока пользователь не прокрутил вверх; пока держится,
  видна метка `following tail`.
- **Цвета ANSI.** SGR (`ESC [ … m`) красит текст после себя, и на следующих
  строках, пока другой SGR не изменит или не сбросит его, как в терминале:
  16 цветов — в цветах приложения, 256 и RGB — как в xterm, фон, жирный,
  тусклый, курсив, подчёркнутый, зачёркнутый, инверсия. Другие
  escape-последовательности — курсор, стирание строки, ссылки OSC 8 — не
  показаны, ссылка остаётся текстом. Табуляция, обрезка длинной строки и её
  ширина считаются по показанному тексту; копируется он же, без
  escape-последовательностей.
- **Внизу** — путь к файлу открытой вкладки от каталога графа и кнопки
  `Finder`, `Editor`, копировать путь.

### Окно деталей эффекта

Открывается кнопкой `Open` в `Logs` (выбранный эффект) или двойным кликом по
эффекту на холсте (его последний заход среди показанных эффектов). Занимает
почти весь экран поверх холста, вокруг — точки.

**Верхняя строка:** `Back to canvas`, значок и имя эффекта с местом,
переключатель заходов `‹ Visit 2 of 2 ›` по всем заходам в этот узел среди
показанных эффектов, копия эффекта (`pkg 2 › target 1`), итог
(`finished · 4m 02s`, `running · 2m 14s`, `failed · 0.1s`; у прерванного —
`interrupted` без времени: когда он кончился бы, неизвестно), закрыть. Esc
тоже закрывает.

Ниже две колонки:

- **Эффект.** `Place in code` — `lib/review.dart:49` с кнопкой копирования:
  вставленное в «перейти к файлу» редактора открывает строку. Факты эффекта:
  `Started` с миллисекундами, `Finished` и сколько шёл, `Starts` — все
  запуски и чем каждый кончился, с пометкой прерванных
  (`interrupted — the process stopped`). Внизу — каталог эффекта,
  `Reveal in Finder`, копировать путь.
- **Output.** Вкладки `Output` и `Log`. `Output` — `returned` и размер,
  данные; эффект идёт или прерван — «пока нет»; упал — ошибка со стеком.
  `Log` — лог эффекта, растёт вживую. Внизу — файл открытой вкладки и
  `Open in editor`.

**Данные** показаны в виде `Schema` или `JSON`: `Schema` — поля с типом и
значением, вложенные объекты и массивы сворачиваются, глубже первого уровня
— свёрнуты; `JSON` — текст с подсветкой. Большие данные показаны не
целиком: у JSON — начало, у лога — хвост, и кнопка `Show all`.

Заход, который показывает окно, выбирается: холст и `Logs` под окном стоят
на нём. Слежение идёт как всегда — выбор переходит на новые эффекты, а окно
остаётся на своём заходе.

Двойной клик по эффекту без заходов, и при `Current graph`, открывает окно
только с именем и местом узла.

### Выбор

- **При открытии графа** выбрана самая новая сессия выбранного воркфлоу,
  начатая до открытия, на своём последнем эффекте; таких нет — `Current graph`.
  Начатые позже выбор не перехватывают.
- **Выбран другой воркфлоу** — как при открытии графа.
- **Эффект в ленте** сдвигает холст к своему узлу, если тот не виден, — или к
  вызову либо копиям, внутри которых эффект, а когда они раскрыты на месте, — к
  узлу эффекта в их рамке.
- **Клик по узлу** выбирает в ленте последний из показанных эффектов на нём или
  в нём. Эффектов нет — ничего не происходит.
- **Новые данные выбор не сбрасывают.**

## Когда что-то не так

Заметки висят над холстом слева сверху, под строкой сессии. Заметки о файле
графа видны при `Current graph`, заметки о сессии — при сессии: у неё на
холсте свой снимок. Заметка о воркфлоу, которых нет в файле, видна всегда.

| Что случилось                                         | Что видно                                                                                                                                                                                                             |
| ----------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Файл графа не читается                                | Метка `File unreadable`; заметка `nanoflow.graph.json cannot be read` с ошибкой. На холсте — последний прочитанный граф; если такого ещё не было — `No valid graph yet`.                                              |
| Файл графа удалён, пока он открыт                     | Метка и заметка `File unavailable`; остаётся последний прочитанный граф.                                                                                                                                              |
| Код рядом с файлом графа изменился                    | Заметка `Graph may not match the code` со списком: исходники из `sources`, изменённые или пропавшие, бинарники из `builds`, собранные заново. Новый файл исходников так не заметить.                                  |
| У файла графа есть предупреждения                     | Заметка `2 warnings in nanoflow.graph.json`: место и текст каждого.                                                                                                                                                   |
| В файле графа нет воркфлоу                            | `The graph file has no workflows`.                                                                                                                                                                                    |
| Сессии шли по воркфлоу, которого нет в файле графа    | Заметка `3 sessions of a workflow not in nanoflow.graph.json` с именами: файл может быть устаревшим, его пишет `describe`. Такой воркфлоу есть в выборе; выбран — заметка `Workflow X is not in nanoflow.graph.json`. |
| У воркфлоу нет сессий                                 | Вместо списка сессий — `No sessions yet` и откуда они берутся.                                                                                                                                                        |
| У сессии нет снимка графа                             | Заметка `Session has no snapshot`: сессия показана на файле графа, как он есть. Так же, когда снимок её продолжения — `null`: файла графа тогда не было.                                                              |
| Сессию продолжили на изменённом коде                  | В карточке и в строке сессии — `resumed on changed code`.                                                                                                                                                             |
| Хэш кода сессии не нашёлся в `fingerprint` и `builds` | Заметка `Session ran on other code`, в карточке — `other code`.                                                                                                                                                       |
| Сессия не записала хэш кода                           | Заметка `Session code not checked`, в карточке — `not checked`.                                                                                                                                                       |
| Снимок сессии не читается                             | `Graph of this session cannot be read`.                                                                                                                                                                               |
| В графе нет воркфлоу сессии                           | `The graph has no workflow review`.                                                                                                                                                                                   |
| Эффекты сессии не на графе                            | Заметка `2 effects not on the graph`: до пяти эффектов с местом и число остальных; в `Logs` у них — `not on the graph`.                                                                                               |
| Событие журнала записано не до конца                  | Событие не учитывается, пока не допишется.                                                                                                                                                                            |
| Строка журнала — не событие, или событие незнакомо    | Событие пропущено; в карточке сессии — `Log read incompletely`, почему — в подсказке: первые пять причин и сколько ещё.                                                                                               |

Эффект, оборванный падением процесса, по хранилищу не отличить от идущего,
пока сессию не продолжат. Приложение показывает его как идущий.

## Вне объёма

- Запуск, остановка и продолжение сессий из приложения.
- Решения человека, которых ждёт эффект.
- Системные уведомления.
- Поиск по логам и данным, фильтры сессий.
- Общий список сессий разных файлов графа.
- Сессии на другой машине.
- Linux, Windows, веб и мобильные платформы.
- Mac App Store: туда без песочницы не пускают.
