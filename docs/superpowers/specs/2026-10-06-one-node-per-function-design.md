# Один узел на функцию

Меняет [дизайн code-first](2026-10-03-code-first-design.md), §6.1 и §7.1.
Решения приняты 2026-10-06.

## 1. Зачем

Сейчас узел `call` — место вызова: функция, вызванная в теле из двух мест,
рисуется двумя плитками. Граф должен показывать функцию одним узлом: к ней
ведут стрелки из всех мест, откуда её вызывают, — как в графе, нарисованном
от руки. Тогда, например, ветка рестарта воркфлоу ведёт стрелками в те же
`agreeSpec()`, `agreeCut()`, что и основной поток, а не рисует их копии.

## 2. Решение

- **Узел `call` — функция в теле, а не место вызова.** Все вызовы одной и той
  же функции (того же набора `functions`; для вызова метода интерфейса — того
  же набора реализаций) в одном теле — один узел `call`. Строит его
  `describe`: файл графа сразу правильный.
- **Стрелки.** В узел ведут стрелки отовсюду, откуда вызов достижим; из узла —
  туда, куда код идёт после каждого из вызовов. Одинаковые стрелки (те же
  `from`, `to`, `label`) — одна. Вызовы подряд дают стрелку из узла в себя
  (петлю).
- **`place` узла `call`** — место объявления вызываемой функции
  (`путь:строка` её объявления, в форме `place` файла графа); для вызова
  метода интерфейса — место объявления метода, который вызван (члена
  интерфейса). Подпись под плиткой в UI — это место.
- **Область.** Склеиваются вызовы в пределах одного тела. В теле другой
  функции у вызываемой функции свой узел.
- **Не склеиваются** эффекты (каждый `f.effect(…)` — своё место кода) и узлы
  `copies`.
- **Формат.** `"format": 3`; UI, встретив другой формат, говорит, что файл не
  читается.
- **UI** берёт граф как есть: отметки сессии на `call` и так считаются по
  функциям; пройденные развилки — по рёбрам тела. Двойной клик и «раскрыть на
  месте» — у одного узла.

## 3. Тесты

- `describe`: функция, вызванная в теле дважды (последовательно, в ветках
  `if`, в цикле и вне его, из `switch`), — один узел `call` со стрелками из
  всех мест и к продолжениям всех вызовов; `place` — строка объявления;
  вызовы подряд — петля; вызов метода интерфейса из двух мест — один узел с
  местом метода интерфейса; эффекты с одинаковым именем — по-прежнему разные
  узлы; детерминированный порядок id и рёбер (файл одинаков байт в байт).
- Файл графа примера и фикстуры переписаны `describe`; `--check` проходит.
- UI: граф с функцией, вызванной дважды, — одна плитка, стрелки из обоих мест;
  отметки сессии и пройденные развилки на ней; проверки раскладки пусты;
  золотые картинки с вызовами — посмотреть (подпись — место объявления).
