Как посмотреть одну копию

Три пакета — три копии тела цикла. Копии нумеруются в порядке старта; при наведении на номер — что вернул первый шаг копии, чтобы узнать её (например, «core:uploaded»).

A

Переключатель копий в шапке рамки

В шапке — «все» и номера копий со статусом. Выбрали копию 2: внутри рамки виден только её путь — пройденные шаги с галочкой, текущий подсвечен, не пройденные приглушены. Панель логов под холстом показывает шаги только этой копии.

Копий сотня — вместо кнопок список с поиском и фильтром «идут / упали / готовы». Вложенные копии — путь выбора: «копия 2 › сборка 1».

B

Через цифру на шаге

Клик по зелёной цифре на шаге — список копий, которые сейчас на нём; выбор копии делает то же, что в A. Удобно, когда интересна копия, застрявшая на конкретном шаге.

Дополняет A, а не заменяет: в A можно выбрать и уже закончившуюся копию.
