Вложенность: только обводка

publish() вызывает upload(), а та — sign(). Раскрыты два уровня, третий свёрнут. Рамка одна и та же на любой глубине: серая линия, без фона, поэтому вложенность не темнеет и не пестрит.

Future<void> publish(Flow f, Package p) async { Future<void> upload(Flow f, Package p) async { await upload(f, p); await sign(f, p); // hash → signature final ok = await f.step('verify', …); await f.step('put', …); if (!ok) await f.step('rollback', …); } }
