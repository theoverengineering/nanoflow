# nanoflow

Пакет переписывается: рабочие процессы станут обычными функциями Dart, которые
выполняются в самом процессе, а не программой графа под движком. Пока в
`lib/nanoflow.dart` остаётся только `exec` — запуск внешней программы — и
`ExecException`; как они устроены, написано в комментариях `lib/src/exec.dart`,
а `dart test` проверяет их `test/exec_test.dart`.
