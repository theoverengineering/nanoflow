# nanoflow

Библиотека воркфлоу. Воркфлоу — обычная асинхронная функция Dart
`Future<R> Function(Flow f, I input)`, шаг — вызов `f.step('имя', () => …)`.
`Flow` выполняет функцию в процессе приложения как сессию и пишет её в `runs/`
каталога проекта: вход, запись и события каждого шага, результат.

- `Flow({directory})` — каталог проекта: заданный, иначе каталог бинарника
  собранной программы, иначе ближайший к скрипту предок с `pubspec.yaml`.
- `start(workflow, input)` → `FlowSession` (`id`, `result`); `run` — `start`
  и `result`. Воркфлоу — функция верхнего уровня или статический метод: по
  имени функции названа сессия.
- Каждая сессия идёт в своей зоне, и ключ шага (`collect#1@e3b0c44298fc1c14`)
  одинаков при каждом запуске того же кода, как бы ни шли параллельные копии:
  по нему продолжение после падения найдёт готовые шаги. Устройство — в
  `lib/src/context.dart` (перенесено из `prototypes/step_keys`).
- `resume(workflow, sessionId)` — продолжение после падения: функция идёт
  заново с сохранённым входом, готовый шаг (тот же ключ и тот же
  предшественник `after`) отдаёт сохранённый результат и не выполняется,
  остальные выполняются вживую — в прежнюю запись шага, если она есть.
  Законченная сессия ничего не выполняет: `result` — сохранённый результат
  или `SessionFailedException`.
- `unfinished(workflow)` — id незаконченных сессий воркфлоу.
- Сессию ведёт один процесс (`SessionBusyException`); конец сессии ждёт
  шаги, которые функция не дождалась.
- Сбой хранилища — `StorageException`, остановка `stop()` —
  `FlowStoppedException`: шаги больше не стартуют, в сессию ничего не
  пишется, её можно продолжить.
- Вход, результат и результаты шагов — JSON; иное — `CodecException`.
- `exec` — запуск внешней программы (`lib/src/exec.dart`).
