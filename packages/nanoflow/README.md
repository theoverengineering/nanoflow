# nanoflow

Библиотека для [графа кодом](../../README.md#программа-графа): файл на Dart с
ней сам и есть программа графа. Как пишется граф — в
[графе на Dart](../../docs/dart-graph.md).

## Что внутри

- **Узлы.** `node(функция)` — рабочий узел, `fork(функция)` — развилка;
  функция при объявлении не вызывается. Тип параметра — `in`, тип результата
  — `out`. Параметр `Object?` или `dynamic` — узел без `in`; результат
  `void`, `Null`, `Object?` или `dynamic` — без `out`. Исход `bool` — форма
  if, любой другой тип — switch.
- **Граф.** `Graph.start` и `Graph.part` начинают кусок, `.next` — стрелка
  рабочего узла, `.then` и `.otherwise` — выходы развилки, `Graph([…])`
  собирает куски. Цель — узел или множество узлов; множество может смешивать
  рабочие узлы и развилки. Ошибки формы ловит компилятор: цель не принимает
  данные, исход не того типа, `.then` у рабочего узла, `.next` у развилки,
  продолжение после множества или развилки, кусок как цель.
- **Имена узлов** — имена переменных верхнего уровня, через `dart:mirrors`:
  программа графа запускается `dart run`, не AOT.
- **Типы данных** (`src/dart_types.dart`). `String`, `int`, `double`, `num`,
  `bool`, `List<T>`, `Map<String, T>`, `enum` (по имени) и классы с
  конструктором `fromJson` и методом `toJson`. `schemaOf` даёт схему типа для
  `in` и `out`, `decodeAs` разбирает JSON в значение типа (`FormatException`
  с местом, если не подходит), `encodeValue` пишет значение в JSON.
- **Сборка** (`src/build.dart`). `buildGraph` проверяет граф и даёт узлы по
  имени и граф в JSON; `describe` — описание графа `{file, graph}`, где
  `command` и `decide` — место объявления узла относительно каталога
  программы: `graph.dart:12`. Узлы — в порядке объявления. Ошибки —
  `GraphBuildException`, по строке на каждую: нет `Graph.start`, выход
  объявлен дважды (в том числе в разных кусках), узел не в переменной
  верхнего уровня или в двух, два узла с одним именем, тип данных без
  JSON-формы.

Публичная точка `lib/nanoflow.dart` отдаёт только то, чем пишут граф;
`serve` строится на `lib/src/`.

## Тесты

```bash
dart test
```

`test/compile_errors_test.dart` запускает `dart analyze` на программах из
`test/fixtures/compile_errors/` и сверяет ошибки по строкам; из анализа
пакета эти программы исключены в корневом `analysis_options.yaml`.
