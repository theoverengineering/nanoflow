# nanoflow_ui

Приложение для macOS на Flutter: показывает прогоны графа вживую. Что оно
делает — [ТЗ интерфейса](../../docs/ui-spec.md): стартовый экран, экран
графа и окно деталей шага над ним.

Оно вне pub workspace, со своим `pubspec.lock` (почему — README
«Репозиторий»): зависимости ставит `flutter pub get` в этом каталоге.

## Экраны

| Файл             | Что                                                                                                                                    |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `lib/app.dart`   | приложение: стартовый экран ↔ экран графа                                                                                              |
| `lib/start/`     | стартовый экран, недавние графы (в `shared_preferences`)                                                                               |
| `lib/graph/`     | экран графа (ниже)                                                                                                                     |
| `lib/theme.dart` | цвета и стили текста из [макетов](../../docs/design/)                                                                                  |
| `lib/platform/`  | Finder, редактор, буфер обмена, `~`                                                                                                    |
| `lib/state/`     | данные экрана графа (ниже)                                                                                                             |
| `lib/widgets/`   | общие виджеты: пунктирная рамка, кликабельное, точка статуса, знак «идёт», заметка о сбое, значки, строка пути с кнопками, копирование |

Шрифты макетов — Geist и Geist Mono — лежат в `assets/fonts/` (SIL OFL,
`OFL.txt`). Песочницы macOS нет: приложение читает каталог `runs`, который
пользователь не выбирал.

ничего не решают: правила ТЗ о статусах, временах, счётчиках, метках, пути
прогона, строках `Logs` и выборе — здесь, и у каждого свой тест.

| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `graph_file_source.dart` | файл графа `nanoflow.graph.json`: читается и перечитывается при изменении; ошибка разбора не стирает последний прочитанный граф                                                                           |
| `freshness.dart`         | свежесть файла графа: исходники рядом против `sources`, бинарники рядом против `builds`; код сессии против `fingerprint`/`builds` её графа                                                                |
| `session_feed.dart`      | лента читателя `runs/` рядом с файлом графа, разложенная по сессиям, шагам, журналам; `Log read incompletely`                                                                                             |

| `sessions.dart`          | карточка сессии, строка над холстом, список сессий выбранного воркфлоу; воркфлоу на выбор — из файла графа и те, что шли в сессиях, но которых в файле нет                                                |
| `runs.dart`              | прогоны по порядку, их состояния, унаследованные шаги, какой прогон выбрать при открытии сессии                                                                                                           |
| `graph_marks.dart`       | состояния узлов, метки прогонов, счётчики заходов и стрелок, путь выбранного прогона                                                                                                                      |
| `log_rows.dart`          | заголовок и строки ленты `Logs`, общая шкала времени и её подписи                                                                                                                                         |
| `step_details.dart`      | выбранный шаг для деталей: чей он, есть ли у него вход и выход, а если нет — почему (`—`, «пока нет», сбой)                                                                                               |
| `step_files.dart`        | лог шага, значения документов и их файлы, каталог шага — по запросу, из читателя; `GraphModel.files`                                                                                                      |
| `visits.dart`            | заходы в узел по всей сессии; откуда пришёл вход шага (D7) или `launch input`; запуски шага и прерванные                                                                                                  |
| `visit_details.dart`     | окно деталей шага: заход среди всех, итог, факты шага, описание узла — команда или функция, типы `in` и `out`, куда ведёт                                                                                 |
| `schema_labels.dart`     | метки типов (`#/Change`, `string[]`) и их поля (`{ change, findings[] }`)                                                                                                                                 |
| `json_data.dart`         | данные для `Schema` (строки полей, вложенные открыты на первом уровне) и `JSON` (части строки для подсветки), размер в байтах                                                                             |
| `session_view.dart`      | всё это вместе для выбранной сессии: её граф (снимок или файл графа) и проверка её кода; экспортирует части                                                                                               |
| `selection.dart`         | что выбрано: сессия, шаг; при открытии графа или воркфлоу — самая новая сессия, начатая раньше; слежение за последним шагом                                                                               |
| `body_path.dart`         | уровни графа: тело воркфлоу, затем тела открытых в нём вызовов и копий — насколько их есть в графе; подписи крошек; что открывает узел                                                                    |
| `clock.dart`             | текущее время и тик раз в секунду для идущих длительностей                                                                                                                                                |
| `graph_model.dart`       | всё вместе для одного экрана: воркфлоу (помнится по имени), новые данные — в выбор, снимок — по показанной сессии, граф холста, его уровни и заметки над ним; выводы считаются раз на изменение и секунду |
| `texts.dart`             | как пишутся длительности, время (и с миллисекундами), дни, короткие идентификаторы, тысячи                                                                                                                |

Приложение ничего не запускает: оно читает файл графа и сессии в `runs/`
рядом с ним (спецификация, §9).

## Экран графа

`lib/graph/graph_screen.dart` собирает экран и владеет его `GraphModel`:
создаёт его, когда граф открыт, и освобождает вместе со слежением за
файлами, когда с экрана уходят или приложение закрывают. На холсте один
уровень графа: двойной клик по вызову рисует тело его функции (у вызова
метода интерфейса — сначала выбор реализации), по копиям — тело копии;
крошка в шапке возвращает на свой уровень. Панели `Logs` и окна деталей
шага на экране сейчас нет: они показывают шаги сессии на графе.

| Файл                   | Что                                                                                                                                                                                                                                                                                                                                                                       |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `header.dart`          | шапка: `Graphs`, файл, крошки уровней (`release › publish()`) — крошка выше нарисованного возвращает на свой уровень, шеврон у первой выбирает воркфлоу, когда их несколько, и отмечает те, которых нет в файле; средние крошки, которым нет места, сворачиваются в `…` со списком; каталог; метка `Live` (или что не так с файлом), `Reveal in Finder`, `Open in editor` |
| `sessions_column.dart` | `Current graph`, карточки сессий с полосой статуса, `1 failed`, число шагов, `No sessions yet`                                                                                                                                                                                                                                                                            |
| `session_bar.dart`     | строка сессии поверх холста, заметки — под ней; при `Current graph` её нет                                                                                                                                                                                                                                                                                                |
| `graph_notes.dart`     | поверх холста: файл недоступен или не читается, граф может не соответствовать коду, предупреждения; у сессии — нет снимка, другой код, не проверено; сессии воркфлоу, которых нет в файле графа                                                                                                                                                                           |
| `split_view.dart`      | две панели с границей, которую тянут; панель можно свернуть до заголовка                                                                                                                                                                                                                                                                                                  |

Заметки о файле графа видны при `Current graph`, заметки о сессии — при
сессии: у неё на холсте её собственный снимок. Метка в шапке видна всегда.

## Logs

`lib/graph/logs/` — панель под холстом: лента шагов выбранного прогона и
детали выбранного шага. Строки, заголовок и шкалу дают `lib/state/`,
панель их только рисует. При `Current graph` она пуста; шеврон сворачивает
её до заголовка.

| Файл                     | Что                                                                                                         |
| ------------------------ | ----------------------------------------------------------------------------------------------------------- |
| `logs_panel.dart`        | заголовок `run e5f6 · 8 steps, 7 inherited from k7f2`, лента слева, детали справа                           |
| `step_list.dart`         | строки шагов, `split · run e5f6`, `2 starts`, конец прогона со ссылками, `↑ 8 earlier steps`                |
| `step_bar.dart`          | знак шага и его полоса на шкале сессии, штрихованная у идущего                                              |
| `step_details_pane.dart` | имя узла, вкладки `Input`, `Output`, `Log` (`—`, если узел их не объявляет), `following tail`, `Open`       |
| `log_view.dart`          | лог шага: держится за хвостом, пока его не прокрутили вверх                                                 |
| `document_view.dart`     | документ как JSON; что вкладка пишет вместо данных                                                          |
| `mono_lines.dart`        | строки лога и документа: строятся только видимые, длинные не переносятся, а прокручиваются вбок; `Show all` |
| `file_footer.dart`       | файл открытой вкладки от каталога графа, `Finder`, `Editor`, копировать путь                                |

Клик по шагу выбирает его и сдвигает холст к узлу, если тот не виден
(`GraphCanvasController.revealNode`); выбранная строка всегда в поле
видимости, при слежении — и строки после неё. Лог открывается на конце —
и когда к нему возвращаются с другой вкладки — и держится за хвостом, пока
его не прокрутили вверх. Большой лог показан
последними 1000 строками, большой документ — первыми, до `Show all`;
строки длиннее 2000 символов до него обрезаны — `Show all` есть и тогда,
когда длинна только строка.

Кнопка `Open` открывает окно деталей выбранного шага.

## Окно деталей шага

`lib/graph/details/` — окно над всем экраном графа, вокруг — точки: один
заход в узел. Открывают его `Open` в `Logs` (выбранный шаг) и двойной клик
по узлу: его последний заход в выбранном прогоне, иначе последний в сессии,
иначе только описание узла. Заход, который показывает окно, выбирается, и
холст с `Logs` под окном стоят на нём. Слежение при этом идёт как всегда:
если заход — последний шаг идущего прогона, выбор переходит на новые шаги
прогона, а окно остаётся на своём заходе; закрыли окно (`Back to canvas`, ×
или Esc) — холст и `Logs` на последнем шаге. Что показывать, решает
`lib/state/visit_details.dart`; окно слушает `GraphModel` и часы.

| Файл                       | Что                                                                                                                        |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `step_details_window.dart` | окно: верхняя строка (`Back to canvas`, узел, `Visit 2 of 2`, прогон, итог, ×), три колонки, Esc                           |
| `input_column.dart`        | `from fix · 14:08:54` (переход к тому шагу) или `launch input`, тип `in`, данные; файл документа и `Finder`                |
| `node_column.dart`         | команда или функция (`DECIDE` у развилки), карточки `in` и `out`, `THEN` или исходы, факты шага; каталог шага, копирование |
| `output_column.dart`       | вкладки `Output` (`passes #/Report` и размер, исход развилки, `—`, «пока нет», ошибка) и `Log`; `Open in editor`           |
| `data_view.dart`           | `Schema` — поля с типом и значением, вложенные сворачиваются; `JSON` — с подсветкой, большой — до `Show all`               |
| `parts.dart`               | общее колонок: заголовки, метка типа, заметка вместо данных                                                                |

## Холст

`lib/graph/canvas/` — холст графа: раскладка одного уровня
(`CanvasGraph.levels`) из `lib/layout/`. Холст слушает `GraphModel`; двойной
клик по вызову или копиям — `onOpenNode`, `GraphCanvasController.revealNode`
сдвигает холст к узлу, если тот не виден. Отметок сессии на графе сейчас
нет.

| Файл                   | Что                                                                                                                                                                                                                                                       |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `graph_canvas.dart`    | холст: сдвиг (перетаскивание, колесо, два пальца), масштаб (щипок, ⌘ или Ctrl с колесом, кнопки), сетка, вписывание                                                                                                                                       |
| `canvas_marks.dart`    | тон стрелок, выходов и планок и счётчики; отметок сессии нет — всё `Tone.plain`                                                                                                                                                                           |
| `edges_painter.dart`   | стрелки и планки входов                                                                                                                                                                                                                                   |
| `exit_labels.dart`     | выходы: точки, капсулы; подписи и счётчики на подложке цвета холста                                                                                                                                                                                       |
| `node_tile.dart`       | узел по виду: шаг — терминал, условие — ромб, вызов — стопка из двух плиток с числом шагов `{ 3 }`, копии — из трёх с шагами копии и `×n` на углу стопки, маркеры `start` и `end` — пунктир; имя (длинное обрезано, целиком — в подсказке) и место в коде |
| `legend.dart`          | легенда в правом нижнем углу; у `Current graph` её нет — остаются только кнопки масштаба                                                                                                                                                                  |
| `canvas_style.dart`    | цвета и шрифты холста; `measureLabel` меряет текст для раскладки теми же стилями, какими он нарисован                                                                                                                                                     |
| `layout_geometry.dart` | точки и прямоугольники раскладки в типах Flutter                                                                                                                                                                                                          |

Граф вписывается в холст при первом показе и когда на холсте другой граф
(у сессий разные снимки), но не от новых данных той же сессии; крупнее
нарисованного он при этом не становится. Сверху остаётся место под строку
сессии или под плашки `Current graph` — когда они появляются или уходят,
граф вписывается заново, если вид не двигали, — снизу — под кнопки и
легенду.

## Раскладка графа

`lib/layout/` — где на холсте узлы, выходы и стрелки, по
[алгоритму](../../docs/graph-layout.md). Чистый Dart: Flutter и `dart:ui`
не импортируются, тесты идут на Dart VM.

```dart
final layout = layoutBody(body, functions: file.functions); // GraphLayout
checkLayout(layout); // нарушения правил шага 9, пусто — всё хорошо
countCrossings(layout); // сколько раз стрелки пересекаются
```

Раскладывается одно тело (`GraphBody`): маркер `start`, из которого
выходят рёбра `from: null`, узлы тела и по маркеру `end` на каждое ребро
`to: null` — путь кончается рядом с узлом, откуда выходит. Рёбра узла с
одной подписью — один выход, несколько таких рёбер — капсула.

В `GraphLayout` всё, что рисует холст: плитки, имена (длиннее 30 знаков —
с `…`) и места в коде, что написано в плитке (`start`; у вызова и копий —
`{ 3 }`, сколько шагов может пройти ниже, через вызовы и копии, рекурсия
не считается дважды), место под метки, под плитки стопки и `×n`, планки входов, выходы (точка, капсула), подписи (`true`, `each`,
исходник случая) и место под счётчик, стрелки — ломаная, остриё и куски для
рисования со скруглёнными углами. Координаты от (0, 0). Ширину текста
считает `LayoutOptions.measure`; по умолчанию — приближение моноширинным
шрифтом макета, холст передаст настоящую.

| Файл                | Шаг                                         |
| ------------------- | ------------------------------------------- |
| `geometry.dart`     | точки, прямоугольники, скругление углов     |
| `layout_graph.dart` | граф для раскладки, настройки               |
| `graph_layout.dart` | результат: `GraphLayout`, узлы, стрелки     |
| `cycles.dart`       | 1 — петли и обратные стрелки                |
| `layers.dart`       | 2, 3 — слои и точки прохода                 |
| `ordering.dart`     | 4 — порядок в слое                          |
| `ports.dart`        | 5 — порядок выходов и входов, высота плитки |
| `coordinates.dart`  | 6 — высоты, где тексты и метки узла         |
| `lanes.dart`        | 7 — дорожки, диагонали, x слоёв             |
| `routing.dart`      | 8 — ломаные стрелок                         |
| `checks.dart`       | 9 — проверки и пересечения                  |
| `layout.dart`       | публичное API и сборка шагов                |

## Отступления от ТЗ

Где буква [ТЗ](../../docs/ui-spec.md) не помещается на экран или не
выполнима геометрически, приложение делает так:

- **Узкое окно.** `following tail` сжимается до жёлтой точки, слова — в
  подсказке, когда заголовок деталей шага уже 440 px; колонка таймлайна в
  ленте шагов пропадает, когда ей остаётся меньше 40 px. В окне макетов
  видно всё.
- **Нет графа — нет кнопок масштаба.** При `No valid graph yet` и у сессии,
  чей граф не читается, масштабировать нечего, и кнопок нет, хотя у
  `Current graph` по ТЗ они остаются.
- **Радиус скругления меньше**, где излом короче двух скруглений: углы не
  могут занять больше половины отрезка. Из графов тестов и вариантов
  развилок так выходит только у развилки, все исходы которой ведут в один
  узел (`then: x`, `else: x`).

## Тесты

```bash
flutter pub get
flutter test                  # всё; раскладку можно и dart test test/layout
flutter test --update-goldens # заново снять эталонные картинки экранов
```

Тесты видят шрифты приложения (`test/flutter_test_config.dart`), так что
картинки экранов в `test/goldens/` — с настоящим текстом. Снимают их
`test/support/golden.dart`: окно 1440×900, как у макетов, при плотности 2×;
сравнивать — с PNG из `docs/design/`. Картинки холста (`canvas_*.png`) сняты
в размере холста макета — без колонки сессий, шапки и `Logs`; экрана графа
(`graph_*.png`) — целиком, `graph_review` — в состоянии `graph.png`,
`graph_task` — `task-graph.png` в его окне 2000×1000; `step_details` — окно
деталей шага в состоянии `step-details.png`, с тенями. Шрифты рисуются
по-разному на разных системах, картинки сняты на macOS.

Графы для тестов — файлы графа в `test/layout/graphs/`: `review` из
`examples/review`, файлы фикстур `nanoflow_describe` (`release`, `inline`,
`control` и другие) и прежние графы тестов раскладки (`task` из макета,
петли, капсулы, длинные стрелки), записанные функциями. У каждого тела
число пересечений в эталонной раскладке — `test/layout/reference.json`:
раскладка не должна стать хуже. Картинки эталонных раскладок —
`test/layout/rendered/`; счётчики `1×` на них показывают место, которое под
счётчик отведено.

### Живой тест

`integration_test/live_test.dart` гоняет настоящее приложение против
настоящего движка. Нужен macOS и Dart SDK в `PATH`; в `tool/ci.sh` его нет.

```bash
dart pub get                       # в корне: пакеты для программы графа
cd apps/nanoflow_ui
flutter test integration_test/live_test.dart -d macos
```

Тест собирает `nanoflow` из `apps/nanoflow_cli`, кладёт рядом
`tool/dev/fake-nanoflow-yaml` под именем `nanoflow-yaml` (подмена программы
для YAML, `tool/dev/README.md`) и отдаёт приложению `PATH` с ними первыми.
`examples/review` копируется во временный каталог как `graph.dart` с
`graph.yaml` рядом; `notify` в копии ждёт файла `release`, чтобы сессия шла,
пока тест на неё смотрит. Тест открывает `graph.yaml` кнопкой `Open graph`
(диалог подменён), запускает `nanoflow run` и проверяет, что всё приходит
само: сессия, `running` → `finished`, шаги и лог в `Logs`, счётчики,
прогоны разветвления в переключателе, окно деталей шага; правка
`graph.dart` — в `Current graph`, ошибки `nanoflow check`, удалённый
`graph.yaml` — плашка `File unavailable`. Снимки окна в эти моменты — в
`build/live_screenshots/`; смотреть их рядом с `docs/design/*.png`.

`integration_test/history_test.dart` — длинная история: 200 сессий по 30
шагов, записанных файлами, как их пишет движок. Меряет, через сколько
видна самая новая сессия и вся история и самый долгий кадр при загрузке и
после: новая сессия должна быть видна быстрее 3 секунд, кадр — короче
секунды при загрузке и полсекунды после. Замеры видны в причине провала;
`reportData` их тоже получает, но в файл его пишет только `flutter drive`,
а не `flutter test`.

```bash
flutter test integration_test/history_test.dart -d macos
```
